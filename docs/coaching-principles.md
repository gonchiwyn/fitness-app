## Core & abs (Galpin)

**Core ≠ abs.**
- "Abs" (aesthetics) = rectus abdominis + obliques + transverse abdominis.
- "Core" (function) = abs + pelvic floor, diaphragm, spinal erectors, deep spine,
  QL, glutes, hip stabilizers, sometimes upper back / scap. Training principles
  differ across these — one program does not cover all.

**Three goals — look, feel, perform.**
- *Look:* rectus abdominis hypertrophy. Higher reps, more frequency, flexion
  work, drop sets.
- *Feel:* pain reduction. Anti-movement work, glute + hip stabilizer, deep
  spine loading. Never flexion-under-load if history of back pain.
- *Perform:* force transmission. Stability > movement. Anti-rotation carries,
  anti-lateral flexion, anti-extension holds.

**Core is stability-first.**
- Baseline activation is ~2–3% MVC — muscles that are almost always on.
- Modern coaching (McGill onward): reduce spinal movement under load; train
  anti-flexion, anti-rotation, anti-extension, anti-lateral flexion.
- Movement-based crunches / sit-ups OK for aesthetic goals; contraindicated for
  people with back pain history.

**Movement patterns to cover:**
1. Flexion  →  situp, crunch, hanging knee raise (aesthetic focus)
2. Lateral flexion  →  side bend
3. Extension  →  back extension, reverse hyper
4. Rotation  →  Russian twist, medicine ball throws
5. Anti-flexion  →  hollow hold, dead bug, standing plank
6. Anti-rotation  →  pallof press, suitcase carry, bird dog
7. Anti-extension  →  ab wheel, plank (proper)
8. Anti-lateral flexion  →  side plank, single-arm farmer carry

**Frequency + volume rules-of-thumb:**
- Core recovers fast, can train 3–4× per week without overtraining.
- Don't stack heavy compound work AND heavy dedicated core in the same session
  if either is truly max-effort — the core is already working during compounds.

## VO2 max & endurance (Galpin)

**Why it matters.**
- VO2 max is one of the strongest all-cause mortality predictors — 2–4× more
  predictive than blood pressure, cholesterol, or smoking history.
- No known upper ceiling: higher VO2 → longer life. Continuous return.

**The equation.**
- VO2 = HR × stroke volume × avO2 difference.
- Two bottlenecks: *central* (heart / stroke volume) and *peripheral*
  (muscle O2 extraction, mitochondrial density).

**Training zones (rough).**
- *Blue* (Zone 1–2): 60–65% HRmax, RPE 2–4, conversational, mostly nose-breathing.
  Long duration, low CNS cost, builds mitochondria + capillary density.
- *Green* (Zone 3): 65–85% HRmax, RPE 5–7, moderate. Tempo / fartlek range.
- *Red* (Zone 4): 85%+ HRmax, RPE 7–9. HIIT range, hard.
- *Infrared* (Zone 5): 95%+ HRmax. Not linear cost — recovery burden is
  exponential. Dose sparingly.

**Norwegian model (Oscar Svendsen distribution):**
- ~75% of training time at 60–82% HRmax (blue)
- ~20% at 83–87% (green tempo/threshold)
- ~5% at 88%+ (red / infrared)

**"Repeat peak power" — an under-used protocol.**
- 5–7 seconds all-out, 60s rest, 8–10 rounds.
- Work:rest ratio 1:5 to 1:12 (60s rest per 5–10s work).
- Trains repeated maximal power without accumulating fatigue that would
  degrade output. Different from HIIT (which is 30–60s work + short rest —
  builds anaerobic capacity, not peak power).

**Rules of progression.**
- No more than ~10% volume OR intensity increase per week. Not both.
- Adding intensity always feels smaller than adding volume — respect the
  compound effect over 6–8 weeks.
- New runners: build tissue tolerance (Pogo hops, jump rope, Achilles loading)
  before adding running volume. Ankle injury / Achilles rupture is the #1
  running attrition failure.

**Program archetypes (Metamorphosis / Joel Jameson).**
- Foundation phase (weeks 1–4): 5 days/week alternating easy / moderate.
  Steady-state + tempo/fartlek. Small volume increases each week.
- Peak phase (weeks 5–8): 6 days/week. Add one hard/red day mid-week.
  Repeat-peak-power intervals start here.
- Test week (8): submaximal Cooper 12-min run works as VO2 max proxy.

**Fartlek vs Tempo vs Intervals (Joel Jameson usage):**
- *Fartlek:* continuous movement, rolling intensity, no discrete rest. Rolling hills.
- *Tempo:* continuous, sustained slightly above easy, "conversational-hard."
- *Intervals:* discrete work + discrete rest, higher intensity per bout.

## Cardio modality rules

**Steady-state Z2 = run / bike / row / ski erg / brisk hill walk only.**
- Never burpees, jumping jacks, or plyo-based work as a Z2 exercise.
- The point of Z2 is aerobic base + mitochondrial density under sustained,
  controlled HR. Plyo / high-CNS moves defeat the purpose.
- Substitutions inside a cardio / recovery / stretching session must stay
  in the steady-state family.

## Warmup principles

**Tissue tolerance before volume.**
- If the day is a running / cardio day, include a small dose of Achilles
  loading (Pogo hops, jump rope) as part of the warmup. 2–3 minutes.
- Purpose is joint tolerance, NOT cardio prep.

**Day-specific movement prep.**
- Push day: T-spine mobility + shoulder / scap activation.
- Pull day: scap engagement + T-spine.
- Legs day: hip mobility + squat-pattern grease-the-groove.
- Cardio day: hip flexor open + easy ramp to Z2 pace.

**Personalized always-on layer (Gonzalo profile).**
- Chronic lumbar care: glute activation + anti-extension core primer in every
  warmup, regardless of day type.
- Left scap deficit: scap activation (band pull-apart / Ys / face pull) in every
  warmup.

## Push:Pull:Legs balance

**Symmetry non-negotiable.**
- Modern life is already push-dominant (typing, phone use, driving).
- Push volume ≥ Pull volume creates shoulder and posture issues. Attia is
  strongest here — MED framework requires at least 1:1 Push:Pull.
- If a 7-day preset can only fit 5 lifting slots after 2× Z2:
  - **PPL classic:** 2 Push + 2 Pull + 1 Legs (single hard Legs day, symmetric upper).
  - Never 2 Push + 1 Pull + 2 Legs — that's the "chest and quad guy" imbalance.

## Focus block phases (Galpin's wave-of-progression)

**Every block runs Accumulation → Intensification → Realization → Deload.**
- *Accumulation:* build volume tolerance. Moderate loads, add sets.
- *Intensification:* +5% load, slight rep drop. Push harder, moderate volume.
- *Realization:* peak week. Loads +8%, main lift +1 set, accessories -1 set
  (conserve energy for PR attempts).
- *Deload:* cut intensity ~15%, drop a set across the board. CNS recovery
  is necessary, not optional. One week per block minimum.

**Distribution scales with block length.**
- 4-week block: 2 Acc / 0 Int / 1 Real / 1 Deload (short but valid).
- 6-week: 2 Acc / 2 Int / 1 Real / 1 Deload.
- 8-week: 3 Acc / 3 Int / 1 Real / 1 Deload.

## Weekly review feedback loop

**Data that has downstream generator effect (skip anything else):**
- Energy 1–5 → accessory volume adjustment (Drained → -1 set, Charged → +1).
- Sleep quality (Poor / OK / Good) → accessory volume, phase severity.
- Per-exercise "hard" flag → -1 set on that exercise next occurrence.
- Per-exercise "easy" flag → +1 set.
- Main-lift "Beat" / "Hit" / "Missed" → next week's rep-range target.
- Body-flag zone → auto-toggle activeConcerns (injury swaps).

**Explicitly do NOT collect:**
- Motivation (currently). Not actionable for this user.
- Open-ended text (won't be processed → won't be honored).

## Injury handling policy

**Two-layer model.**
- `chronicLumbarCare` (always-on): caps hinge/squat intensity at ~78% 1RM,
  adds glute activation to warmup, prefers RDL over conventional deadlift.
  Doesn't blanket-swap anything.
- `activeConcerns` (opt-in per-flare): triggers hard swaps for the flagged
  zone (bench → incline DB press, back squat → goblet, etc.).

**Nordic curl + hip thrust exclusion.**
- Excluded from all pools for the current user until posterior chain /
  unilateral strength catches up. Progression: single-leg glute bridge →
  banded glute bridge → cable kickback → step-up → back extension →
  single-leg RDL BW → weighted single-leg RDL → hip thrust → Nordic.
